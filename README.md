# Remove Background Apps

Dua desain aplikasi hapus background foto yang berjalan 100% di browser (satu file HTML, tanpa server, tanpa upload).

| Desain | Folder | Gaya |
|---|---|---|
| Gunting Studio | `gunting-studio/` | Cerah, neo-brutalist ala sticker sheet |
| Nirlatar | `nirlatar/` | Gelap, darkroom, dock melayang, slider before/after |

## Fitur
- Hapus background otomatis (baca warna tepi) atau pilih warna manual
- Toleransi, halus, kikis, kuas hapus/pulihkan, undo/redo
- Ganti latar (warna, gradasi), outline stiker, bayangan
- Ekspor PNG transparan, salin ke clipboard

## Catatan
Metodenya berbasis warna, bukan model AI. Paling bagus untuk background polos atau gradasi halus.

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages dari branch `main`.
